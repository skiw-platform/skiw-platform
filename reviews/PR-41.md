- Category: defect
- Rule: UNI-16; reviewer §7 executable operator runbooks.
- Evidence: `docs/runbooks/host-rebuild.md:122–127` says to run after `docker compose up -d db`, then shows prepare followed directly by apply. The disposable project was cleaned up.

Severity is P2 rather than the usual failed-guardrail P1 because this is an isolated documentation/order defect, later bullets already state the right dependency, and it does not weaken authentication or disclose data.

Remove the conflicting opening prerequisite and include the db startup between prepare and apply in the command block. Retain the separate subnet-change instructions.
