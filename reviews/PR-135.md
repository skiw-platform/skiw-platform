1. **"Nothing in M3a–M3i requires a passkey"** (§3 M3g, factor-change bullet): with M3g now last but inside the letter range M3a–M3i, this reads as including M3g. Say "Nothing built before M3g requires a passkey".

This can be done in the M3h PR itself rather than here.
