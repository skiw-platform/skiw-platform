- Category: defect (accessibility), caused by a spec decision; **not introduced by this PR**
- Rule: A11Y-01 / FE-05 (skip link moves focus, not the page); slice spec decision 2 ("any other hash reads as Today")
- Evidence: `App.tsx` `pageOf()` maps every hash except `#security` to Today; the skip link is `href="#main"`; `hashchange` → `turn("today")`. - Required correction: owner chooses (plan §5 Q1): amend decision 2 so a non-page hash keeps the current page, or make the skip link move focus without changing the hash. Then the builder fixes it with a browser test on Security at both widths.
