### [P3] The runbook's chat-id snippet can use an environment proxy and can list a stranger's chat
- Category: material risk (small)
- Rule: amendment §7 "Bot token leaks" (no environment proxy); UNI-08
- Evidence: `docs/runbooks/health-alerts.md` step 4 uses `urllib.request.urlopen(...)` with the
  default opener, which honours `https_proxy`; the code itself uses `ProxyHandler({})`
  (`infra/host/skiw_host/alert.py`, `Telegram.send`). The snippet prints every chat id in
  `getUpdates`, and a bot username is public.
- Failure scenario: a root shell that keeps `https_proxy` (`sudo -E`, or a sudoers `env_keep`)
  sends the token URL through the proxy. Or someone else sends `/start` to the new bot before the
  owner runs step 4, and the owner copies the wrong id.
- Required correction: build the opener with `urllib.request.build_opener(urllib.request.ProxyHandler({}))`
  in the snippet; say "expect exactly one id; more than one: rotate nothing, but check which chat is
  yours (send a message and rerun) before step 5".
- Owner: builder. Verification: read the runbook. Status: open (non-blocking).

### [P3] The apt stamp file is an assumption; if it is missing, `security-updates` alerts forever
- Category: material risk (small)
- Rule: UNI-03 (fail closed, which it does); amendment §9 M1k proof
- Evidence: `health.py` `LISTS_STAMP = "var/lib/apt/periodic/update-success-stamp"` [A], from
  `update-notifier-common`. `host-rebuild.md` line 16 installs only `nftables gnupg`; nothing in
  the repo installs `update-notifier-common`.
- Failure scenario: an Ubuntu 24.04 image without that package. Every run is bad
  (`cannot read (FileNotFoundError)`), and after 48 h the owner gets this alert plus a reminder
  every 6 h. It is noisy, not silent, and M1k sees it first.
- Required correction: at M1k, confirm the file on both hosts. If it is missing, add
  `update-notifier-common` to the `host-rebuild.md` install line, or use another stamp, and record it.
  The PR body, DECISIONS "Still OPEN" and the runbook "Not proven yet" already list this check.
- Owner: builder (M1k). Status: open (non-blocking).
